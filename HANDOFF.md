## 1. What this is

A personal developer portfolio for "Brainilio". The homepage is one long scroll through a series of low-poly 3D
dioramas, all drawn by vanilla three.js on a single shared WebGL canvas, with plain HTML text layered on top. There is
also a "Lab" (`/journey`) of standalone 3D experiments, a projects archive (`/projects`) and project detail pages
(`/project/[slug]`).

## 4. Homepage architecture (`src/app/(home)/`)

`page.js` renders `home.js` (client component). Key ideas:

### 4.1 Sections, scroll state, sky
- Five sections in order, slot indices: **Home=0, About=1, Work=2, Skills=3 (`SKILLS_AT`), Contact=4**.
- Each section is a `.ht-zone`; pinned ones (`.ht-pinned`) are taller (`100svh + steps × 40svh`) so a sticky
  `.ht-stage` (100svh) holds while the section's progress runs 0 → 1. `.ht-zone + .ht-zone` has a 10svh gap.
- A single scroll handler in `home.js` writes a shared mutable ref `scene.current`:
  `progress[slot]` (0–1 while pinned), `live` (slots on screen), `tilt[slot]` (camera tilt while arriving/leaving,
  `ARRIVE=14`, `DEPART=10`), `section` (dominant slot). React state `section` and `stop` drive text.
- One fixed CSS sky behind everything (`.ht-sky-live`): a 5-stop gradient interpolated between per-section palettes
  (`SKY` array in `home.js`: dusk → blue hour → sunset → warm desert morning → Big Sur blue).
- A fixed `.ht-finish` overlay adds grain, vignette and a light leak. A section menu pill (`.ht-pill`) shows progress.
- A loading screen (`.ht-loader`) prefetches every GLB in `MODELS` (in `home.js`) and waits for each scene's
  `onReady`; in dev it takes ~30 s.
- Lenis smooth scroll; `MotionConfig reducedMotion="user"`; every scene checks `prefers-reduced-motion`.

### 4.2 The shared stage (`stage.js`)
- One fixed, transparent, full-screen WebGL canvas (`.ht-world`, z-index 2, pointer-events none), one renderer
  (pixel ratio ≤ 1.5, ACES tone mapping), one rAF loop for the page's life.
- Scenes call `getStage().register({ mount, scene, camera, draw(dt), exposure, fade?, overscan? })` and get an
  unregister function. Each frame the stage calls every `draw(dt)` (returns true if something changed), then renders
  each visible scene into its `mount` element's on-screen rectangle (stages are sticky, so islands travel with the page).
- `overscan` (default 0.5): renders into a rect grown above/below so geometry can spill past the stage edge; the
  projection is squeezed to compensate. It may be a number or `{ top, bottom }` (Skills uses `{ top: .5, bottom: 0 }`).
- `fade` (`{ side: "left"|"right"|"top"|"bottom", from }`): a veil quad that erases toward that edge so the island
  melts into the CSS sky. `from: 1` = no fade; it's read every frame so a scene can animate it (Skills does).
- The mount elements stay in the DOM as transparent hit areas, so pointer handling works per scene.

### 4.3 Sections in detail
1. **Home / hero** – `island-scene.js`: a floating low-poly island (river, waterfall, pines, animals from `kit.glb`,
   stag/deer/fox etc.), centred framing. The name is an HTML `<h1 class="ht-name ht-title">Brainilio</h1>` at the top,
   **behind** the canvas (z-index 1) so the peaks overlap it. Bottom-left intro with two buttons (`.ht-button`
   "See my work" and ghost "Say hello").
2. **About** – `about-scene.js`: campfire island with the original **ranger bear** (`ranger-bear.js`), river with
   faceted water (`volume:.2`). Its copy sits beside the island (`data-side="right"`).
3. **Work** – `work-showcase.js` (not on the shared stage: it has its own two canvases, sky behind the text and eagle in
   front). A sunrise sky with clouds and fading stars; a **flying bald eagle** (`eagle-flying.glb`, wing flap in the
   vertex shader) circles round the big project name, passing behind and in front of the letters. Three bent, warping
   picture "sheets" show the project images; a new project is revealed by a sweep of warm light. Project names animate
   letter by letter (motion). The heading "Things I've built" is gradient ink that follows the sunrise via CSS vars
   `--warm` and `--rise` set from the loop. Projects come from `src/lib/projects.js` (first 4 with `previewImage`).
   Phones get a plain list (`.wl-phone`, `.wl-phone-head{margin-top:-100svh}`).
   **New (uncommitted):** as the Work section scrolls away, the eagle breaks its circle and dives out through the bottom.
4. **Skills** – `skills-scene.js` + `desert-parts.js`: see §5.
5. **Contact** – `coast-scene.js`: Big Sur coast (cliffs, ocean shader, sea stacks, Bixby-style bridge, lighthouse whose
   beam follows the pointer, fog, gulls, kayaks, orca/shark/sea lion). `fade:{side:"top",from:.78}`, `overscan:0`.
   A glass contact card with a Formspree form (`FORMSPREE` constant in `home.js`), a mailto link, a beam hint and the
   model credits (`.ht-credits`). Several `max-height` media queries keep the card clear of the credits on short screens.

### 4.4 Shared builders
- `island-parts.js`: `random(seed)` (seeded RNG, use it, not Math.random, for stable layouts), `faceted(tris, colorOf)`
  (flat-shaded vertex-coloured geometry from triangles), `createIsland`, **`createWater`** (faceted low-poly water:
  waves only lift, foam on crests/banks/fall, an inner "depth" sheet plus side walls for volume; `volume`, `uShallow`,
  `uDeep`, `uBright` etc.), `createCloud`, birds, eagle, bear material, fish, `createSpin` (drag-to-spin).
- `forest-parts.js`: `paintGeometry(g, hex)` (adds a vertex colour), `mergeFlat(parts)` (non-indexed merge dropping uv
  and normal; use this instead of `mergeGeometries` when parts have mismatched attributes), trees, flowers, sway shader.
- `park-parts.js`: `createSign(skill, i)` (wooden park sign with canvas-lettered face; scale 0.4 in Skills), half dome,
  sandstone fins, basket, geyser.
- `bison-rig.js`: rigs the unrigged bison mesh in a shader; `createBisonAnimator(rig, {seed, resting})` with
  `update(dt, { moving, gait, eating, resting, alarmed })`.
- `wagon.js`: `loadWagon(loader, {length}, onLoad)` returns a `wheelSpin` uniform.
- `content.js`: `SKILLS` (title, items, lead, blurb), `TOOL_ICONS` (tool → Tabler icon file), `EXPERIENCE`.
- `model-credits.js`: credits rendered in the Contact section.
- Not used by the homepage any more but kept for the Lab: `prairie-scene.js`, `prairie-cards.js`, `roadtrip-scene.js`,
  `hike-scene.js`, `work-meadow.js`, `work-scene.js`, `work-wildlife.js`, `shine-card.js`, `perf.js`.

### 4.5 Styles
- `src/app/(home)/home.css` (all homepage styles, prefixed `ht-` and `wl-`), `src/app/globals.css` (site-wide; defines
  `--page-max-width:1440px`, `--gutter`), `src/app/journey/journey.css`, `lab-grid.css`.
- Inside `.ht`, `--gutter` is recomputed on wide screens so content aligns to the 1440px max-width container.
- Ink colour on light skies: `--ink:#2a1636`, violet accent `#7c5cdb` / `--violet:#a78bfa`.

## 5. Skills section (most recent work, partly uncommitted)

A **side-on road trip through the American Southwest**, like a diorama cross-section. The camera never travels along the
road; the world slides past in **parallax layers**: `SPEED = { far:.08, rocks:.18, plants:.35, near:1, front:2.2 }`
(each layer group's `x = -drive × speed`). Each scroll stop (`STEP = 12` world units) drives the wagon (fixed at
`WAGON_X = -.6`) to the next of five park signs (one per skill group, `SIGN_AHEAD = 2.4`). Drive eases with
`1 - exp(-dt·3.7)`; re-entering from far away snaps instead of driving. Clicking the wagon calls `onCar` (scrolls to the
next stop). Renders at full rate while moving, 30 fps idle, only while live.

Layers and contents (all procedural in `desert-parts.js` unless noted):
- **far**: rolling plain, two rugged ridgelines (`createRidge`, blue haze and red-brown).
- **rocks**: Monument Valley-style buttes (`createMonument`: talus mound plus 1–3 columns of different heights with
  jagged, broken tops), a low red ridge, a dust-haze band.
- **plants**: Joshua trees, junipers, saguaros, scrub on rolling ground (`rolling(amount, seed)` height function).
- **near** (moves with the road): ground (flat along the road, rolling in front and behind; `nearAt(x,z)`), road and
  dashes, split-rail fences in runs with gaps and **broken ends** (`createFence(..., { broken: ["start"|"end"] })`), a
  pond with reeds and cottonwoods (`createPond`, `POND` constant), three bison at the pond (two drinking), one resting,
  one lone bull much later (`bison.glb`); a grazing **horse** (`horse.glb`, Quaternius CC0, AnimationMixer alternating
  Eating / Idle_Headlow); an abandoned **cabin** (`createCabin`); prickly pear (`createPricklyPear`); **tumbleweeds**
  that occasionally roll through (`createTumbleweed`); the park signs, turned `-0.34` rad toward the wagon, with a glow
  halo on the active one and a **cowboy hat** hanging on sign #3's post (`createHat`); the wagon (`wagon.glb`) with a
  blob shadow and dust puffs.
- **front**: soft-focus foreground plants (canvas-blurred sprites from `blurredPlant("saguaro"|"agave"|"grass")`) close to
  the camera, partly covering the frame edge at some stops and sweeping past between stops (fake depth of field; no
  post-processing).
- Sky: sun sprite, clouds, and the flying bald eagle circling top-centre (`cx = -1.4`, y ≈ 5.9).

Camera: two poses blended. `rest` (side-on, road in the lower third) and `sky` (up with the eagle and clouds). Tall
(phone) screens use separate values. `arrive = smooth(stageTop/innerHeight × 1.15)`: arriving from Work the camera
starts in the sky and pulls back down to the road.

Transitions (**uncommitted**):
- **Work → Skills eagle hand-off:** the Work eagle dives out (`work-showcase.js`, `leaving` from the pin's rect, `dive`
  and `swoop`); the Skills eagle is hidden until then (`flight.visible = entry < .96`) and descends from above the frame
  into its circle (`entry = smooth((arrive - .2)/.62)`). Only one eagle is visible at a time.
- **Skills → Contact:** Skills no longer overscans below its stage (that used to paint desert over the coast's top). As
  Skills leaves (`leave` from the stage's bottom edge), the camera lifts part-way toward the sky pose and a bottom fade
  (`fade.from = 1 - .8·smooth(leave·1.6)`) dissolves the land into the CSS sky, so the coast rises into open sky.

Text (`home.js` + `home.css`, **uncommitted**):
- On wider screens (`min-width:761px`): heading "What I bring along" top-left; the current stop spelled out **top-right**
  of the content container at the same height (`--skills-top`): kicker "Stop N of 5 · Title", large `lead`, `blurb`,
  then **tool chips with Tabler logos** (`.ht-skill-tools`, icons via CSS `mask` with `--icon`). Animated with
  AnimatePresence + `STORY_LINE` variants (blur/fade/rise, staggered), keyed by stop.
- The old glass card list was removed; a visually hidden `<ol className="ht-sr">` keeps the full list for screen readers
  (the visible story is `aria-hidden`).
- Phones: story at the top (`top:76px`), heading at the bottom.

## 9. Gotchas learned the hard way

- Turbopack HMR often keeps stale three.js scenes; do a full page reload after scene edits. The in-app browser must be
  visible to render WebGL. The loading screen takes ~30 s in dev.
- `mergeGeometries` fails on mismatched attributes (uv/normal); use `mergeFlat`.
- Things drawn in a scene's overscan are not covered by its fade veil (the veil only covers the stage rect).
- Two copies of the eagle (Work and Skills) are separate objects in separate renderers; keep their timing in sync so
  only one is ever on screen.
- The page gutter differs from the global one inside `.ht` on screens ≥ 1300px.
- Rotation conventions: the eagle model faces +z; with rotation order "YXZ", positive x-rotation pitches it nose-down.
- Gradient headings: the Work title and project names need generous padding (`.12em .12em .26em` and similar) so g/y
  descenders aren't cut.
